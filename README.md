# Proyecto Integrador: Automatización de Infraestructura Digital

Repositorio destinado al desarrollo y documentación de prácticas de automatización de redes.

## Avance del proyecto integrador

### Práctica 1
Preparación de la estación de automatización de redes.  
**Estado:** Completada.

### Práctica 2
Construcción de la red simulada en GNS3.  
**Estado:** Completada.

### Práctica 3
Primer programa de Python para representar información de dispositivos.  
**Estado:** Completada.  
Se desarrolló un programa en Python capaz de representar y mostrar información básica de los dispositivos de la infraestructura simulada, incorporando funciones de filtrado y búsqueda.

**Próximo paso:** Desarrollar programas que permitan procesar y automatizar información relacionada con la infraestructura de red.
